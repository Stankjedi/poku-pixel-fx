# 네이티브 높이 조각

`pixel-sculpt`는 직접 그린 픽셀의 색을 유지하면서 조명에 사용할 **큰 부피와 주름**을 작성한다.
바위의 둥근 면, 검날의 능선, 옷의 접힘을 높이 지도로 만들고, 그 결과의 법선을 재조명과 표면 맵 출력에 사용한다.
높이는 네이티브 픽셀을 단위로 하는 명시적인 값이다. 그림의 RGB에서 깊이를 추측하지 않는다.

## 기본 API

```ts
import {
  sculptPixelHeight2D,
  applyPixelHeightDeltas2D,
  refreshPixelHeightNormals2D,
} from 'poku-pixel-fx/core/pixel-sculpt';

const stroke = sculptPixelHeight2D(sprite, [
  {x: 28, y: 40, pressure: .45},
  {x: 46, y: 34, pressure: 1},
], {
  mode: 'raise', size: 17, strength: 3,
  hardness: .35, symmetry: 'none', wrap: false,
  selection: selectedRegion,
  protectedMask: protectedDetails,
  // height: authoredForm, // channels가 없는 원화의 초기 높이
});

// stroke.sprite.channels: material / height / normal
// stroke.touched와 stroke.deltas: 원본 캔버스와 같은 길이
const indices = Array.from(stroke.touched.keys()).filter(i => stroke.touched[i]);
const deltas = indices.map(i => stroke.deltas[i]);
const reopened = applyPixelHeightDeltas2D(sprite, indices, deltas, {
  strength: 1, wrap: false, protectedMask: protectedDetails,
  // height: authoredForm, // 처음 조각할 때 사용한 초기 높이와 동일하게 전달
});
```

원본에 `channels`가 있으면 해당 높이·재질·법선을 사용한다. 초기 `height` 옵션은 채널이 없는 원화에 적용된다.
원본에 채널과 초기 높이가 모두 없으면 평평한 높이 0, 재질 ID 0, 화면 앞으로 향하는 법선에서 시작한다.
빈 sparse 편집도 초기 표면을 만들 수 있다. 따라서 재질 무늬로 색을 다시 칠하지 않고 PNG를 재조명 가능한 표면으로 준비할 수 있다.

## 네 가지 도구

| 모드 | 작성하는 것 | `strength` |
|---|---|---|
| `raise` | 높이 올리기 | 붓 중심에서 더할 네이티브 높이 |
| `lower` | 높이 내리기 | 붓 중심에서 뺄 네이티브 높이 |
| `flatten` | `targetHeight` 쪽으로 맞추기 | 0..1 혼합률, 1보다 크면 1로 적용 |
| `smooth` | 주변 높이와 연결하기 | 0..1 혼합률, 1보다 크면 1로 적용 |

`size`는 완전한 필압에서의 정수 지름이며 1..256이다. 기본값은 16이다.
`strength` 기본값은 1이며 음수가 아닌 유한한 float32 범위의 값이다.
`hardness`는 일정한 강도를 유지하는 안쪽 반경의 비율이며 0..1, 기본값은 .5이다.
그 바깥에서는 부드러운 곡선으로 강도가 줄어든다. `targetHeight` 기본값은 0이다.

`smooth`는 스트로크 시작 시점의 3×3 높이 이웃을 가중 평균한다. 불투명한 실루엣 셀만 이웃으로 사용하며,
투명한 배경을 높이 0으로 끌어들이지 않는다. 이 연산은 높이에만 작용하고 원화의 색·알파·실루엣은 그대로 유지한다.

## 스트로크와 필압

한 번의 스트로크에서는 붓이 지나간 **최대 강도**를 사용한다.
같은 지점을 여러 번 지나거나 포인터 이벤트가 더 촘촘하게 들어오거나 좌우 대칭 붓이 겹쳐도 한 번의 제스처 안에서 높이가 계속 누적되지 않는다.
새로운 스트로크를 시작하면 앞서 완성한 높이를 기준으로 추가 조각할 수 있다.

직선 구간 사이에는 연속적인 붓 영역이 있다. 필압은 구간을 따라 선형으로 변하는 반경을 결정한다.
중간에 같은 직선·같은 필압 변화의 샘플을 추가해도 같은 기하학적 영역을 작성한다.
0 필압의 독립적인 점은 아무것도 작성하지 않는다. 입력 좌표는 네이티브 셀로 내림하고,
짝수 지름은 기존 픽셀 붓과 같은 오른쪽·아래쪽 반 셀 중심을 사용한다.

미리보기는 매번 **스트로크 시작 전 원본과 전체 포인터 경로**에서 다시 계산한다.
이전 미리보기 결과에 다음 포인터 이벤트를 계속 덧붙이면 제스처 단위의 높이 계약이 깨진다.

## 선택·보호·반복 경계

- `selection`은 높이를 바꿀 위치를 제한한다.
- `protectedMask`는 높이와 원래 법선을 모두 유지한다. 얼굴·문양·경계 등 손으로 보정한 부분을 보존할 수 있다.
- `symmetry`는 `none`, `x`, `y`, `xy`를 지원한다. 짝수 붓의 전체 footprint도 대칭 이동한다.
- `wrap:true`는 캔버스 양 끝으로 붓과 높이 이웃을 이어 준다. 여러 번 감긴 붓이 같은 목적지에 도착해도 최대 강도로 합친다.
- 1픽셀인 축도 처리한다. 같은 셀로 이어지는 축의 높이 기울기는 0이다.

픽셀이 실제로 존재하려면 실루엣 마스크가 0이 아니고 원본 알파도 0이 아니어야 한다.
독립 마스크로 가린 셀, 투명 셀의 숨은 RGB, HDR 발광, 의미 마스크와 배치 메타데이터는 바꾸지 않는다.

## 법선과 저장 계약

법선 좌표는 `+x` 오른쪽, `+y` 아래쪽, `+z` 관찰자 쪽이다.
양쪽 높이 이웃이 있으면 중앙차분을, 한쪽만 있으면 한쪽 차분을 사용한다.
평면이 캔버스 경계나 실루엣의 구멍을 만나도 사용할 수 있는 방향의 경사가 갑자기 절반이 되지 않는다.

높이가 바뀌면 그 셀과 직접 인접한 네 셀의 법선도 다시 계산할 수 있다.
선택 바깥의 이웃 법선은 새로운 표면에 맞추지만, 보호된 법선은 유지한다.
`touched`에는 실제 높이가 바뀐 셀만 포함된다. 법선만 갱신된 이웃을 높이 편집으로 기록하지 않는다.

색을 칠하거나 지워 실루엣의 점유가 바뀐 뒤에는 `refreshPixelHeightNormals2D(sprite, changed, options)`로
해당 셀과 네 이웃의 법선을 다시 연결할 수 있다. `changed`는 전체 캔버스 길이의 점유 변화 마스크다.
이 함수는 높이·재질·원화 버퍼를 그대로 유지하고 필요한 법선만 갱신한다.
색만 바뀐 셀은 이 마스크에 포함하지 않는다. 변화 마스크가 비어 있으면 원래 객체를 그대로 반환한다.

문서에서는 표시된 높이 레이어 이후의 그림·곡선 레이어가 점유를 바꾸면 이 갱신을 수행한다.
곡선은 해당 곡선 레이어의 보호 영역을 사용한다. 이미 작성된 그림 레이어는 저장된 셀을 적용하고 새 경계의 법선을 연결한다.
이전 높이 스트로크의 보호 마스크를 뒤의 모든 편집에 영구적으로 전파하지 않으므로 변형 뒤의 옛 좌표가 잠금 영역으로 남지 않는다.
높이 레이어가 없는 기존 문서의 재생 동작은 유지한다.

`deltas`는 전체 캔버스 길이의 float32 덧셈 값이며, 변경하지 않은 셀은 0이다.
희소 저장 시 `touched`의 인덱스를 오름차순으로 기록한다.
`applyPixelHeightDeltas2D`는 중복되거나 순서가 잘못된 인덱스, 잘못된 배열 길이, 유효하지 않은 수치를 거부한다.
희소 레이어의 `strength`로 효과를 조절하면 원본 높이에서 다시 계산할 수 있다.

여러 스트로크를 같은 레이어에 합칠 때는 실제 표면 높이·법선과 재질 요철을 제외한 작성 높이가 순차 적용과 같아야 한다.
큰 높이의 상쇄 뒤 작은 획처럼 float32 덧셈 순서가 영향을 주거나 원래의 직접 작성한 법선과 차이가 생기면
새 높이 레이어에 다음 연산을 보관한다. 레이어 공간이 없으면 기존 문서를 유지한 채 편집을 거부한다.

미리보기 결과도 저장할 float32 delta를 통해 계산하므로 같은 원본과 옵션에서 다시 열었을 때 높이·법선이 일치한다.
매우 큰 높이에서는 float32로 표현할 수 있는 간격보다 작은 변화가 사라질 수 있다.
높이 또는 덧셈 값이 float32 범위를 벗어나면 입력을 변경하지 않고 연산 전체를 거부한다.

색·알파·실루엣·HDR 버퍼는 이 함수에서 수정하지 않으며 결과에서도 같은 원본 버퍼를 참조할 수 있다.
높이와 법선이 변경되면 독립적인 새 채널을 반환한다. 기존 채널에 실제 변화가 없으면 원본 객체를 그대로 반환한다.

## 검증 범위

`tests/pixel-sculpt.test.mjs`는 명시적 높이의 초기화, 평면 법선, 높이 단위와 혼합,
연속 경로·필압·대칭·반복 경계, 독립 실루엣과 보호 영역, 원본 RGBA/HDR 보존,
float32 delta 재생 및 실패 원자성을 검사한다.
색을 더 많이 쓰거나 무늬가 더 촘촘해졌다는 미술적 품질 점수를 만들지 않는다.
