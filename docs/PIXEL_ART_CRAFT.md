# Pixel Art Craft — 곡선과 높이를 직접 작성하기

Pixel Art Lab에서 **색을 그리는 작업, 큰 형태를 만드는 작업, 표면의 부피를 만드는 작업**을 따로 조절할 수 있습니다.
가져온 다색 원화의 RGB를 재질 색으로 덮어쓰지 않고 높이를 조각한 뒤 조명을 적용할 수 있으며,
곡선은 적용한 다음에도 제어점을 다시 움직일 수 있습니다.

이 도구는 기존 Pixel Art Lab과 같은 주소에서 동작합니다. 기존 효과 원화와 기본 렌더링은 바꾸지 않습니다.

```sh
npm ci
npm run build
npm run gallery
```

`http://127.0.0.1:8080/gallery/pixel-art-lab.html`을 열고 그리기 도구에서 **높이 올리기 · H** 또는 **곡선 경로 · P**를 선택하세요.

## 편집 가능한 예제로 시작하기

작업 화면의 **깃 장식 열기**와 **천 주름 열기**는 새 도구를 함께 사용한 160×192 원화입니다.
각 외곽선·색 덩어리·장식·높이·조명은 편집 레이어에 남습니다.

- **깃 장식:** 휘어진 외곽, 굵기가 변하는 깃 결, 금속 중심 줄기와 직접 조각한 부피를 확인합니다.
- **천 주름:** 큰 색면과 높이로 만든 주름, 직접 설계한 자수 군집, 에나멜 장식의 조합을 확인합니다.

예제를 연 뒤 레이어의 **설정**을 누르면 곡선의 점이나 높이 배율을 수정할 수 있습니다.
새 예제를 여는 작업도 실행 취소에 포함하므로 이전 원화로 돌아갈 수 있습니다.
기존 카탈로그 이펙트를 수정한 전후 비교가 아니라, 작성 기능을 보여 주는 별도의 예제입니다.

## 1. 색을 보존하면서 높이 만들기

PNG를 가져오거나 빈 캔버스에 색을 그린 다음 **높이 올리기**를 선택합니다.
색이 있는 셀에 높이를 더하며, 지우개처럼 실루엣을 늘리거나 RGB를 바꾸지 않습니다.
처음 높이 도구를 선택하면 높이 보기를 열어 붓의 결과를 확인하기 쉽게 합니다.
**원화 보기 / 높이 보기 / 법선 보기** 버튼으로 언제든 표시를 바꿀 수 있습니다.

| 도구 | 바뀌는 것 | 활용 예 |
| --- | --- | --- |
| 올리기 | 현재 높이에 세기만큼 더함 | 둥근 덩어리, 접힌 천의 융기, 검날의 능선 |
| 내리기 | 현재 높이에서 세기만큼 뺌 | 접힌 틈, 홈, 낮은 접촉면 |
| 높이 맞추기 | 지정한 목표 높이 쪽으로 이동 | 평평한 장식판, 일정한 높이의 모서리 |
| 높이 정리 | 인접한 높이 쪽으로 조정 | 높이만 급하게 튀는 부위의 연결 |

**지름**은 네이티브 셀 단위이며 1~256입니다. **단단한 중심**을 크게 하면 가운데 넓은 부분의 높이가 일정해지고,
작게 하면 가장자리까지 완만하게 이어집니다. 이 변화는 기하 높이에만 적용됩니다. 색상에 이미지 흐림을 적용하지 않습니다.

올리기·내리기의 **세기**는 네이티브 픽셀 높이입니다. 높이 맞추기·정리에서는 0~1 사이의 혼합 강도이며,
1보다 큰 값은 완전 적용으로 처리합니다. 같은 획을 여러 번 지나거나 펜 이벤트가 조밀해져도 한 획의 높이가 중복 가산되지 않습니다.
새 획으로 다시 그리면 그때는 새 높이 변화가 추가됩니다.

Alt를 누른 채 셀을 클릭하면 그 셀의 높이를 **목표 높이**로 가져옵니다.
펜 필압을 켜면 붓 지름이 바뀌며, 색과 알파는 그대로입니다.

### 선택·보호·반복 경계

상단의 **선택 내부만**, 대칭 설정과 디테일 보호를 함께 사용할 수 있습니다.
높이를 바꾼 셀의 주변 법선은 새 기울기에 맞게 계산합니다. 보호한 셀은 높이와 기존 법선도 유지합니다.
투명한 셀에는 높이를 만들지 않으므로, 새 형태를 만들 때는 먼저 연필이나 곡선 채움으로 색과 실루엣을 작성하세요.

**반대쪽 경계로 이어서 조각**을 켜면 타일의 한쪽에 걸친 붓이 맞은편에도 적용됩니다.
경계를 넘는 높이와 법선이 연결되므로, 반복 재질의 큰 융기와 홈을 직접 조정할 수 있습니다.
공간 좌표를 먼저 잘라서 가운데로 긴 선을 만드는 방식으로 처리하지 않습니다.

### 높이 레이어와 실행 취소

완성한 획은 `height` 레이어에 희소한 높이 차이로 저장합니다.
현재 선택한 최상단 높이 레이어가 표시되어 있고 잠기지 않았으며 배율 1·반복 경계·보호 조건이 같으면 다음 획을 같은 레이어에 더합니다.
각 획은 별도의 실행 취소 단위입니다.

중간 레이어나 배율이 조정된 레이어 위에서 새로 그리면 새로운 높이 레이어를 만듭니다.
이를 통해 화면에서 본 현재 높이를 기준으로 새 획을 작성할 수 있습니다.
기존 높이 레이어의 **설정**에서는 전체 높이 차이에 적용할 0~4배 배율을 미리 보고, 적용하거나 취소할 수 있습니다.
배율을 바꾸어도 작성한 원래 높이 차이는 보존합니다.

높이를 작성하면 기존 **원화 색을 유지하는 재조명**과 **Normal / Height / AO / Shadow PNG**를 사용할 수 있습니다.
높이 조각 자체는 색을 바꾸지 않으며, 조명 레이어를 적용할 때 비로소 원화의 명암이 바뀝니다.

## 2. 직접 조절하는 곡선 경로

**곡선 경로 · P**를 선택하고 오른쪽 결과 캔버스에 점을 놓습니다.

1. **클릭**하면 모서리 점이 생깁니다.
2. **누른 채 드래그**하면 그 점의 양쪽에 곡선 핸들이 생깁니다.
3. 기존 **점**을 드래그하면 연결된 핸들도 함께 이동합니다.
4. **핸들**을 드래그하면 접선과 굽힘을 조절합니다. 기본적으로 반대쪽 핸들도 대칭으로 움직입니다.
5. Alt를 누르거나 **양쪽 핸들 연결**을 끄면 한쪽 핸들만 움직일 수 있습니다.
6. **경로 레이어 적용** 또는 Enter로 확정하고, Escape나 **경로 취소**로 초안을 버립니다.

선택한 점은 드롭다운에서도 고를 수 있고 X/Y 좌표를 숫자로 입력할 수 있습니다.
방향키는 1셀, Shift+방향키는 10셀 이동입니다. Delete/Backspace 또는 **점 삭제**로 선택한 점을 제거합니다.
**곡선 점**은 제어 핸들을 만들고, **모서리 점**은 핸들을 제거합니다.
이 버튼은 키보드 조합이 없는 터치 화면에서도 사용할 수 있습니다.

### 열린 선, 채움과 굵기

- **열린 선:** 선 굵기를 정하고 머리카락·자수·식물 줄기·윤곽의 일부를 작성합니다.
- **열린 선의 굵기 변화:** 시작과 끝의 굵기를 따로 정합니다. 굵기는 제어점 수가 아니라 실제 경로 길이에 따라 변화합니다.
- **닫힌 모양:** 마지막 점을 첫 점과 연결합니다. 직선으로 둘러싼 면은 세 점 이상으로 만들고, 곡선 핸들을 사용하면 한두 점으로도 닫힌 곡선을 만들 수 있습니다. 닫힌 선은 이음매가 끊기지 않도록 일정한 굵기를 사용합니다.
- **안쪽 채우기:** 닫힌 모양 안을 현재 색으로 채웁니다. 선 굵기를 0으로 두면 채움만 만듭니다.

색·대칭·픽셀 퍼펙트·선택 내부만·투명도 잠금은 상단 도구 설정을 사용합니다.
경로의 **알파**는 0~255로 직접 정할 수 있습니다. 저장된 반투명 경로를 다시 열고 점만 움직여도 기존 알파가 유지됩니다.

제어점은 연속 좌표를 사용하지만 최종 coverage는 네이티브 셀의 이진 마스크입니다.
RGB 보간이나 흐림으로 곡선을 매끈하게 보이도록 처리하지 않으며, 곡선 안내선·점·핸들은 별도 화면 오버레이입니다.
PNG와 표면 맵에는 들어가지 않습니다.

### 적용 후 다시 수정하기

레이어 목록에서 경로의 **설정**을 누르면 저장한 점과 핸들이 다시 나타납니다.
굵기, 색, 알파, 닫힘과 채움을 조정한 다음 적용하면 **같은 ID의 레이어**가 바뀝니다.
취소하면 이전에 적용한 경로가 유지됩니다. 현재 보이는 유효한 경로 초안은 프로젝트 저장과 프레임 전환 전에 확정됩니다.
선 굵기가 0이고 채움도 꺼진 경로는 선 굵기를 정하거나 채움을 켜야 적용할 수 있습니다.

큰 곡선만으로 최종 원화가 완성되는 것은 아닙니다. 큰 형태를 만든 뒤 색 덩어리·높이·재질을 조절하고,
작은 윤곽과 장식은 원본 크기에서 연필과 명암 붓으로 마무리하세요.

## 3. 같은 조명·팔레트 레이어를 조정하기

이제 재조명과 팔레트도 레이어 목록의 **설정**에서 다시 편집할 수 있습니다.

- 선택한 레이어의 현재 값을 읽어 미리보기를 만듭니다.
- **조명 수정 적용 / 팔레트 수정 적용**은 기존 ID와 순서를 유지합니다.
- **수정 취소**는 저장한 레이어를 바꾸지 않고 원래 결과로 돌아갑니다.
- 수정 중 프로젝트를 저장하면 현재 미리보기 설정을 확정합니다.
- 32개 레이어 한도에서도 기존 레이어의 수정은 가능합니다.

UI에 없는 추가 광원이나 세부 조명 설정은, 관련 항목을 바꾸지 않는 한 저장된 값을 유지합니다.
예를 들어 밝기 적용 강도만 조정한다고 세 번째 광원이나 별도로 작성한 방향을 두 개의 기본 광원으로 바꾸지 않습니다.
팔레트 수정도 저장된 선택·보호 영역과 물체 좌표를 보존합니다.

팔레트 설정의 **디더링 강도**는 규칙 패턴에 배치할 보조색의 양을 조절합니다.
디더링을 **없음**으로 선택하면 가장 가까운 팔레트색으로 매핑합니다.

## 4. 문서·애니메이션과 표면 데이터

정지 원화는 기존 `poku-pixel-art/v2`, 애니메이션은 각 원화 문서를 담는 `poku-pixel-art/v3`에 저장합니다.
새 `path`와 `height` 레이어를 지원하도록 검증·렌더·복제·히스토리·용량 계산을 확장했습니다.
기존 v1/v2/v3 문서와 이펙트의 기본 출력은 유지합니다. 새 레이어를 지원하지 않는 과거 버전의 편집기에서는 새 문서를 열 수 없습니다.

| 저장 요소 | 보존 내용 |
| --- | --- |
| 원화 | 정확한 packed RGBA, 독립 실루엣, 선택과 보호 |
| 경로 | 각 점과 절대 제어점, 채움·굵기·대칭·알파 |
| 높이 | 실제 변경한 셀과 Float32 높이 차이, 배율·반복 경계·보호 |
| 프레임 | 각 cel의 독립적인 곡선·높이·색·조명 레이어 |
| 실행 취소 | 완성한 높이 획, 경로 적용, 기존 레이어 수정 단위 |

높이와 곡선은 그림 레이어와 같은 순서로 재실행되므로 이동·회전·반전과 함께 변형됩니다.
새 재질의 명시적 작성 높이 연결은 아래쪽에 있는 높이 레이어를 따라갈 수 있습니다.
기존에 저장된 재질의 독립 높이 스냅샷은 그대로 읽습니다.

현재 모습 굽기와 표면 맵 출력은 작성한 높이·법선을 보존합니다.
Height PNG는 기존 규약대로 범위 정보를 동반하는 8비트 시각적 맵이고, 정확한 높이 값은 편집 프로젝트에 남습니다.

## 5. API로 사용하기

```ts
import { sculptPixelHeight2D, rasterizePixelPath2D } from 'poku-pixel-fx';
import {
  renderPixelArtDocument2D, writePixelArtHeightLayer2D,
} from 'poku-pixel-fx/authoring';

const before = renderPixelArtDocument2D(document);
const stroke = sculptPixelHeight2D(before, [
  { x: 30, y: 80 }, { x: 38, y: 52 }, { x: 45, y: 25 },
], {
  mode: 'raise', size: 20, strength: 4, hardness: .2,
  selection, protectedMask, wrap: false,
});
document = writePixelArtHeightLayer2D(
  document, stroke.deltas, stroke.touched, undefined, { protectedMask },
);

const coverage = rasterizePixelPath2D(96, 96, [
  { point: [12, 74], out: [15, 15] },
  { point: [78, 36], in: [58, 5] },
], { startWidth: 6, endWidth: 1, pixelPerfect: false });
```

`sculptPixelHeight2D`는 입력 스냅샷을 변경하지 않고 새 sprite·변경 마스크·높이 차이를 반환합니다.
한 획의 미리보기는 같은 시작 스냅샷에 다시 적용해야 하며, 이전 미리보기의 결과 위에 재차 더하지 않습니다.
`writePixelArtHeightLayer2D`에 기존 높이 레이어 ID를 전달하면 저장된 차이에 획의 차이를 합칩니다.

`rasterizePixelPath2D`는 그리기나 선택에 사용할 이진 마스크를 반환합니다.
편집 가능한 경로로 저장하려면 문서의 `path` 레이어에 같은 `nodes`와 `options`, packed `color`를 넣습니다.

## 검증 경로

```sh
npm run test:pixel-art
GPU_BROWSER_PATH=/path/to/chromium node tools/pixel-art-craft-browser-harness.mjs
```

브라우저 하네스는 실제 포인터로 높이를 그리거나 제어점을 움직이고, 프로젝트 파일을 다시 열며,
PNG의 원본 RGBA·보호 영역·프레임 독립성·레이어 재편집·좁은 화면을 확인합니다.
코어 검사는 높이/법선 규약과 곡선의 native coverage, 반복 경계와 저장 재현성을 확인합니다.
검사 결과는 해당 동작의 재현 근거이며, 원화의 미술적 완성도나 실제 GPU 성능을 나타내는 점수가 아닙니다.
