# Distinguishing newly generated energy from fire

## Scope and diagnosis

Baseline: 7724181b01c7985f7cee698a59e279ee2688423e. Four actual CLI generations (fire/energy,
dash/plume) were compared at native 384×256 pixels, six times, with original and identical
unlit palettes. The previous energy plume read as purple fire. Dash primary silhouettes overlapped
strongly despite different colors. Shared flame-like supports, lifetime and erosion, rather than
palette alone, were the main reusable cause. This task changes only new material-volume energy
recipes and adds one reusable local charge renderer. Saved effects and fire are preserved.

A smooth oval charge body was rejected because it read as an icon/capsule. An angular version still
kept a separate static primary. The retained version instead builds primary and detached matter
from overlapping unequal, short-lived charge packets with the same local spend law. They compact,
briefly discharge and exhaust. The source path, event clocks, palette and explicit light budgets
remain. Birth velocity follows the actual tangent; a 400 px/s inherited-speed cap contains extreme
supported dashes. This is stylized material behavior, not a physical electromagnetic solver.

## Observed result and limits

Final native sheets, matched-palette/unlit sheets and adjacent frames were inspected for seed 218,
default seed 1 and independent seed 17. Independent static visual review found coherent irregular
energy mass, changing silhouette and compact discharge, without the rejected detached oval or a
continuous noodle trail. The comparison GIF exports full authored timelines at nominal 40 fps,
using alternating 20/30 ms GIF durations. It does not crop or scale the 384×256 source panels.

The change is bounded: energy can still read as compressed flame/turbulence, the plume as a squat
tuft and the dash as a busy clump. The warm, dense pixel-game reference is not matched by this
technical primitive alone. Full-speed playback, user acceptance, unmistakable material identity,
finished premium initial quality and Unreal/Niagara equivalence are not established. No automatic
viewing confirmation has been entered. Rapid exhaustion can leave an empty part of the preserved
ending window. Plume core clipping does not constrain every independent shed particle.
