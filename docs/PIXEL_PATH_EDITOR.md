# 편집 가능한 픽셀 곡선

머리카락의 큰 흐름, 옷의 주름, 잎의 윤곽과 가는 장식을 **점과 손잡이로 작성한 뒤 네이티브 픽셀로 렌더**하는 도구다. 곡선의 점과 손잡이를 저장하므로 마지막 적용 후에도 형태를 다시 고칠 수 있다. 열린 선의 양 끝 굵기를 다르게 지정하면 한 픽셀 끝으로 좁아지는 선을 만들 수 있다.

출력은 정해진 해상도의 0/1 마스크다. 블러, 반투명 외곽, 확대된 이미지의 축소 처리를 사용하지 않으며, 색은 별도의 그리기 단계에서 작업 팔레트로 정한다. 넓은 면을 채운 뒤에는 높이·명암·재질이나 직접 그리기로 내부 구조를 작성한다. 곡선 도구 자체가 해부학이나 재질을 추측하지 않는다.

## 작업실에서 작성

Pixel Art Lab의 **곡선 경로** 도구에서 캔버스에 점을 놓고 손잡이를 조절한다. 열린 선은 시작과 끝의 굵기를 따로 지정하고, 실루엣을 채우려면 경로를 닫는다. 저장된 경로 레이어를 다시 열어 점·손잡이·굵기와 색을 수정할 수 있다. 선택과 보호 영역, 투명도 잠금은 적용 범위를 제한한다.

- **점:** 곡선이 통과하는 위치다. 모서리를 의도한 점은 손잡이를 점 위에 두거나 제거한다.
- **나가는 손잡이:** 이 점에서 다음 점으로 출발하는 방향과 곡률을 정한다.
- **들어오는 손잡이:** 이전 점에서 이 점으로 들어오는 방향과 곡률을 정한다.
- **닫힌 경로:** 마지막 점에서 첫 점으로 연결한다. 마지막 점의 나가는 손잡이와 첫 점의 들어오는 손잡이도 사용한다.
- **채우기:** 닫힌 윤곽 내부를 채운다. 선 굵기를 0으로 두면 내부만 채운다.
- **끝 굵기:** 열린 선의 전체 길이를 따라 폭이 변한다. 짧은 구간에 점을 더 놓아도 그 구간에서 폭이 급격히 바뀌지 않는다.

최종 PNG에는 편집용 점과 손잡이 표시가 포함되지 않는다. 경로 레이어가 있는 프로젝트를 저장하면 다시 편집할 수 있다. PNG만 저장한 뒤에는 점과 손잡이 정보가 남지 않는다.

## 네이티브 API

```ts
import { rasterizePixelPath2D, validatePixelArtPath2D } from 'poku-pixel-fx/core/pixel-path';
import { paintPixelMask2D } from 'poku-pixel-fx/core/pixel-brush';
import { hex } from 'poku-pixel-fx/core/color';

const path = validatePixelArtPath2D([
  { point: [12, 48], out: [14, 10] },
  { point: [48, 18], in: [34, 6], out: [67, 30] },
  { point: [86, 42], in: [76, 48] },
], {
  strokeWidth: 5,
  startWidth: 5,
  endWidth: 0,
  pixelPerfect: true,
});

const mask = rasterizePixelPath2D(96, 64, path.nodes, path.options);
const artwork = paintPixelMask2D(source, mask, hex('#f1dfb3'), {
  selection,
  protectedMask,
  alphaLock: true,
});
```

`validatePixelArtPath2D`는 입력 배열을 바꾸지 않고 `{nodes, options}`의 새 값을 반환한다. `point`, `in`, `out`은 모두 **절대 네이티브 좌표**다. 상대 오프셋이 아니며 소수 좌표를 사용할 수 있다. `in`이나 `out`이 없으면 그 손잡이는 해당 점 위에 놓인 것으로 처리한다. 두 점 사이에 손잡이가 모두 없으면 직선이다.

| 옵션 | 기본값 | 의미 |
| --- | --- | --- |
| `closed` | `false` | 마지막 점을 첫 점으로 연결 |
| `fill` | `false` | 닫힌 경로 내부 채우기 |
| `strokeWidth` | `1` | 선의 기본 지름, 0~256 네이티브 픽셀 |
| `startWidth` | `strokeWidth` | 열린 선 시작 지름 |
| `endWidth` | `strokeWidth` | 열린 선 끝 지름 |
| `pixelPerfect` | `false` | 한 픽셀 선의 중복 직각 셀 정리 |
| `symmetry` | `'none'` | `'x'`, `'y'`, `'xy'`로 최종 픽셀 영역 대칭 |

닫힌 선은 시작과 끝이 같은 위치에서 만난다. 이음매에 갑자기 굵기가 바뀌지 않도록 시작과 끝의 지름이 같아야 한다. 닫힌 도형의 채우기는 짝홀 규칙을 사용하므로 오목한 모양과 자기 교차가 있는 윤곽도 처리한다. 여러 개의 별도 경로나 명시적인 내부 구멍을 작성하는 API가 필요하면 기존 `rasterizePixelContour2D`의 여러 `move` 명령을 사용한다.

## 픽셀과 폭의 규약

열린 선은 연필과 동일하게 좌표의 소수 부분을 내림하여 해당 네이티브 셀에 잉크를 놓는다. 채운 윤곽은 연속 좌표를 유지한 상태에서 셀 중심 `(x + 0.5, y + 0.5)`을 검사한다. 따라서 선이 없는 사각형을 `[2,2]`에서 `[9,7]`까지 채우면 가로 7칸·세로 5칸이다. 여기에 외곽선을 더하면 경계 셀도 추가될 수 있다.

곡선은 최대 오차 1/8셀을 기준으로 적응 분할하고, 분할된 점 사이를 끊김 없이 연결한다. 시작·끝 폭의 보간은 캔버스에 자르기 전의 연속 경로 길이를 기준으로 한다. 같은 곡선의 일부만 보이거나 같은 직선에 점을 더 넣어도 전체 길이에 따른 굵기 배분을 유지한다. 양의 폭은 최소 한 셀의 정수 지름으로 표현하며, 폭 0인 끝점은 별도 점을 찍지 않는다. 가까운 구간의 폭이 넓으면 그 구간이 끝점 셀을 덮을 수 있다.

한 점만 있는 열린 선은 점 하나의 붓 자국이다. 전체 길이가 0이면서 양 끝 폭이 다르면 둘 중 큰 지름을 사용한다. 닫힌 단일 점에 두 손잡이를 지정하면 자기 자신으로 돌아오는 곡선을 만들 수 있다. 대칭은 최종 셀 범위를 반사해 합치므로 짝수 굵기와 겹치는 대칭선에도 새로운 알파가 누적되지 않는다.

픽셀 퍼펙트 옵션은 얇은 선의 계단에서 불필요한 직각 셀을 정리한다. 의도한 각진 장식이나 작은 모서리가 바뀌면 이 옵션을 끈다. 원본 그림의 다른 픽셀을 지우는 정리 기능은 아니다.

## 용량과 보존

가로·세로 각각 1~4096픽셀, 경로당 최대 1024점, 모든 좌표는 ±1,048,576 범위의 유한 값이다. 열린 선의 분할 결과는 최대 65,536점이며, 실제 브러시와 채우기는 기존 코어의 보간 셀·스팬·스캔라인 작업 예산도 적용한다. 잘못된 값이나 예산 초과는 기존 문서를 바꾸기 전에 거절한다.

이 기능은 새 경로 레이어를 사용할 때만 작동한다. 기존 효과 원화, 기본 Painter, 3D 렌더러와 재생 시간 규약은 변경하지 않는다. 회귀 검사는 네이티브 좌표·연결성·폭·대칭·저장을 확인하며, 선의 미술적 완성도를 점수로 인증하지 않는다.
