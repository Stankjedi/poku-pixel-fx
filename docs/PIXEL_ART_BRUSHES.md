# 픽셀 군집·클론·타일 직접 편집

직접 그린 여러 색의 작은 픽셀 묶음을 붓으로 재사용하고, 현재 그림에서 필요한 부분을 복제하며,
3 × 3 반복 화면 위에서 타일 경계를 가로질러 그리는 작업 흐름입니다.

큰 실루엣과 명암은 먼저 설계하고, 자수·잎·비늘·금속 장식처럼 이미 작성한 세부 묶음을 필요한 곳에 배치하세요.
기본으로 제공하는 작은 잎과 실땀도 사람이 읽을 수 있는 고정 픽셀 배열로 작성한 재사용 예제입니다.
기존 이펙트 카탈로그나 일반 붓의 기본 결과는 바꾸지 않으며, 반복 경계 옵션은 처음에 꺼져 있습니다.

높이와 곡선 작성은 [Pixel Art Craft](PIXEL_ART_CRAFT.md),
headless API와 작업 예산은 [픽셀 군집 브러시 API](PIXEL_CLUSTER_BRUSH.md)를 참고하세요.

## 작업실 열기

```sh
npm run build
npm run gallery
```

`http://127.0.0.1:8080/gallery/pixel-art-lab.html`에서 새 캔버스를 만들거나 프로젝트·PNG를 엽니다.
**직접 만든 픽셀 묶음**과 **현재 그림에서 픽셀 복제** 패널은 필요할 때 펼칠 수 있습니다.

## 1. 선택한 그림을 여러 색의 붓으로 만들기

1. 연필이나 곡선으로 작은 모양을 그립니다.
2. 사각 선택·올가미 등으로 재사용할 영역을 선택합니다. 의도한 여백도 선택에 포함할 수 있습니다.
3. **선택을 붓으로**를 누릅니다. 현재 보이는 결과에서 선택한 영역의 경계 사각형을 가져옵니다.
4. 이름과 **기준 X/Y**를 정합니다. 붓 미리보기에서 셀을 직접 눌러 기준점을 정할 수도 있습니다.
5. **이 붓으로 그리기** 또는 **픽셀 군집 · J**를 선택하고 결과 캔버스에 클릭하거나 드래그합니다.

선택 범위는 가로·세로 각각 128셀까지입니다. 선택 사각형 안의 선택하지 않은 셀은 찍히지 않습니다.
투명한 셀도 경계 계산에 포함되므로, 주변 여백을 유지한 채 작은 무늬를 캡처할 수 있습니다.
전체 선택이 너무 크면 필요한 부분만 선택한 뒤 캡처하세요.

### 원본 색과 기준점

군집은 저장한 straight RGBA를 그대로 사용합니다. 부분 알파도 유지하며, 알파가 0이거나 숨겨진 붓 셀은 목적지를 바꾸지 않습니다.
상단의 한 가지 그리기 색과 일반 붓 크기는 군집에 적용하지 않습니다.
미리보기는 원본 붓이며, 밝은 테두리로 표시한 기준 셀이 포인터를 따라갑니다.

기본 기준점은 가운데 셀입니다. 짝수 크기에서는 가운데 왼쪽 위 셀을 사용합니다.
예를 들어 잎의 줄기 끝이나 장식의 연결점을 기준으로 정하면 배치 위치를 맞추기 쉽습니다.

| 설정 | 결과 |
| --- | --- |
| 간격 | 획을 따라 정한 정수 픽셀 거리마다 군집을 한 번 배치 |
| 90° 단위 회전 | 원본 픽셀 셀과 기준점을 함께 회전 |
| 좌우·상하 반전 | 회전하기 전에 원본의 해당 축을 반전 |
| 선택 내부만 | 선택한 목적지 안에서만 변경 |
| 디테일 보호 | 보호한 목적지의 색·알파 유지 |
| 투명도 잠금 | 이미 보이는 목적지의 알파를 유지하고 RGB만 변경 |
| 반복 경계 | 군집이 걸친 전체 영역을 반대편 경계에 이어 배치 |

군집은 대칭 대신 회전·반전 설정을 사용합니다. 필압이 0인 샘플은 건너뛰며,
양의 필압에서는 원본 픽셀 크기와 알파를 유지합니다.

### 일정한 간격

간격이 5이면 획의 시작에서 0, 5, 10, 15…셀 거리마다 배치합니다.
끝점이 이 간격에 맞지 않으면 끝에 추가 자국을 만들지 않습니다. 클릭 한 번은 군집 하나를 배치합니다.

포인터가 보낸 중간 샘플 수가 간격을 바꾸지 않도록, 실제 연속 좌표의 길이를 먼저 계산하고
각 군집의 중심을 네이티브 셀로 바꿉니다. 대각선도 중간 샘플을 먼저 계단 모양으로 잘라서 길이를 늘리지 않습니다.
각 미리보기는 획을 시작하기 전의 같은 그림에서 다시 계산합니다.

### 붓 파일

**붓 저장**은 `.poku-pixel-brush.json` 파일을 만듭니다. **붓 열기**로 다른 프로젝트에서도 사용할 수 있습니다.
이 파일에는 이름, 원본 크기, RGBA, 독립 실루엣 마스크, 기준점이 들어갑니다.
간격·회전·반전은 현재 도구 설정이며 원본 붓 파일의 픽셀을 바꾸지 않습니다.

현재 목록에는 최대 32개 붓을 둘 수 있습니다. 목록은 세션 동안 유지하므로 다시 사용할 붓은 파일로 저장하세요.
**목록에서 제거**는 현재 목록에서만 지웁니다. 이미 그린 픽셀이나 내려받은 파일은 그대로 유지됩니다.

## 2. 현재 그림에서 픽셀 복제하기

**클론 · C**를 선택합니다. 처음 클릭하면 읽을 원본 기준을 정합니다.
그 뒤 다른 곳에서 드래그하면 해당 기준에서 읽은 픽셀을 그립니다.
Alt + 클릭으로 기준을 다시 지정하거나, 터치 화면에서는 **복제 기준 고르기**를 누른 뒤 원하는 곳을 누르세요.
**원본 X/Y → 좌표로 지정**으로 정확한 셀을 지정할 수도 있습니다.

청록색 십자는 읽는 위치를 보여 줍니다. 이 안내선은 PNG와 표면 맵에 포함되지 않습니다.
일반 붓 크기·원형/사각형 붓끝·대칭·픽셀 퍼펙트·필압을 사용할 수 있습니다.
선택과 보호, 투명도 잠금은 복제 목적지를 제한합니다.

### 한 획 안에서 고정하는 원본

클론은 획을 시작할 때 보이는 결과를 한 번 가져와 그 획이 끝날 때까지 읽습니다.
목적지가 읽는 영역과 겹쳐도 방금 그린 색을 재귀적으로 읽지 않습니다.
다음 획에서는 그 시점의 현재 그림을 새 원본으로 사용합니다.

**다음 획에서도 복제 간격 유지**를 켜면 첫 획에서 정한 원본→목적지 이동량을 다음 획에도 유지합니다.
끄면 매 획의 시작 위치가 지정한 원본 기준을 읽습니다.
기준을 다시 고르거나 반복 경계 설정을 바꾸면 목적지 기준을 다시 정합니다.

투명하거나 숨겨진 원본 셀은 목적지를 바꾸지 않습니다.
반복 경계가 꺼져 있을 때 캔버스 밖의 원본을 읽으면 해당 셀도 유지합니다.
반복 경계가 켜져 있으면 원본을 읽는 좌표도 반대편으로 이어집니다.

## 3. 3 × 3 반복 화면에서 직접 그리기

**타일 위에서 이어 그리기**를 누르면 반복 경계 옵션과 3 × 3 타일 화면을 함께 켭니다.
현재 도구가 반복 경계를 지원하지 않으면 연필을 선택합니다.
타일 화면의 가운데 테두리는 원본 한 타일이며, 주변 여덟 칸은 같은 그림의 반복입니다.

그 화면 위에서 경계를 가로질러 드래그하세요. 예를 들어 가로 16셀 타일의 X=14에서 X=18까지 그리면
14, 15, 0, 1, 2번 셀이 바뀝니다. 포인터를 먼저 14→2로 잘라서 중앙을 가로지르는 선을 만들지 않습니다.
일반 결과 캔버스에서도 붓끝이 경계에 걸리면 반대편으로 이어집니다.

| 도구 | 반복 화면에서 편집 |
| --- | --- |
| 연필·지우개·직선 | 획과 붓끝을 반대편에 이어 그림 |
| 팔레트 한 단계 밝게·어둡게 | 같은 반복 coverage에 팔레트 단계 변경 적용 |
| 픽셀 군집 | 여러 색의 군집 전체와 기준점을 연결 |
| 클론 | 그리는 위치와 읽는 위치 모두 반복 경계를 따름 |
| 사각형·타원 | 반복 옵션을 비활성화하며 일반 결과 캔버스에서 사용 |
| 높이 조각 | 별도의 **반대쪽 경계로 이어서 조각** 설정을 사용 |

타일 배율은 1×, 2×, 4×, 8×로 조절할 수 있습니다. 큰 반복 화면은 패널 안에서 스크롤합니다.
타일 화면의 안내 테두리와 클론 십자, 군집 범위는 출력 그림에 들어가지 않습니다.
저장하는 PNG 크기도 원본 한 타일 크기입니다.

## 레이어, 실행 취소와 저장

군집과 클론은 현재 보이는 색을 정확히 복제하기 위해 **맨 위의 표시된 그림 레이어이며 불투명도 1인 레이어**를 선택했을 때 그 레이어에 더합니다.
중간 레이어나 불투명도가 조절된 레이어를 선택했다면 새 최상단 그림 레이어를 만듭니다.
이미 합성된 색에 레이어 불투명도나 이후 조명이 다시 적용되는 일을 피하기 위한 동작입니다.

각 완성한 획은 한 번의 실행 취소 단위입니다. Escape는 진행 중인 획을 취소합니다.
프로젝트나 PNG를 저장할 때 진행 중인 획은 먼저 적용합니다.
레이어 한도에 도달해도 선택한 최상단 그림 레이어에 계속 그릴 수 있습니다.

결과 픽셀은 일반 그림 레이어에 희소한 변경 셀로 저장되므로, v2 프로젝트와 v3 애니메이션의 각 프레임에서도 재현됩니다.
복제한 프레임의 그림 레이어는 원래 프레임과 독립적으로 편집합니다.

군집 파일의 원본 RGBA·마스크 바이트는 그대로 보존합니다. 캔버스에 적용한 결과는 일반 그림 레이어의 가시성 규칙을 사용합니다.
군집·클론은 색을 복제하는 도구이며 표면 높이와 법선을 원본 위치에서 함께 이동하지 않습니다.
입체 형태까지 옮기려면 선택 변형을 사용하거나 [높이 조각](PIXEL_ART_CRAFT.md)으로 형태를 작성하세요.

## 브라우저 검증

```sh
npm run build
GPU_BROWSER_PATH=/path/to/chromium \
PIXEL_ART_BRUSHES_REQUIRED=1 \
PIXEL_ART_BRUSHES_REPORT_PATH=/tmp/pixel-brushes-report.json \
PIXEL_ART_BRUSHES_SCREENSHOT_PATH=/tmp/pixel-brushes-workbench.png \
node tools/pixel-art-brushes-browser-harness.mjs
```

하네스는 실제 브라우저의 포인터와 파일 선택을 사용합니다.
수제 예제 붓, 선택 캡처·붓 파일 재열기, 부분 알파, 회전·반전·기준점, 수평·대각선 간격,
선택·보호·알파 잠금, 겹친 클론, 레이어 불투명도, 32층 문서, 실제 3 × 3 경계 횡단,
Escape와 저장 중 획 확정, 프레임 독립성과 390px 레이아웃을 확인합니다.
PNG 기대값은 실제 네이티브 RGBA를 따로 구성해 대조하며 제작용 렌더 함수를 정답으로 호출하지 않습니다.

자동 검사는 데이터와 편집 동작의 보존을 확인합니다. 예술적 완성도나 물리 GPU 성능을 판정하지 않습니다.
