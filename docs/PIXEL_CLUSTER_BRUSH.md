# 수제 픽셀 군집·클론·반복 경계 브러시

직접 그린 자수, 작은 잎, 비늘, 금속 장식처럼 **여러 색으로 구성된 픽셀 군집을 그대로 재사용**하는 도구다. 캔버스의 선택 영역을 브러시로 저장하고, 정수 간격으로 배치하거나 90도 단위로 돌려 사용할 수 있다. 클론 브러시는 선택한 기준점에서 원본 픽셀을 읽어 다른 위치에 그린다. 반복 경계 옵션을 켜면 타일의 오른쪽 끝에서 왼쪽 끝으로, 아래쪽 끝에서 위쪽 끝으로 같은 획을 이어 그린다.

큰 형태와 명암을 먼저 설계하고, 군집 브러시는 반복되는 세부 표현이나 손으로 만든 무늬를 재사용할 때 사용한다. 브러시는 새로운 재질 구조를 추측하거나 랜덤한 잡음을 더하지 않는다. 저장한 색과 픽셀 모양이 작업자가 작성한 그대로 남는다.

## 브러시 캡처와 저장

`capturePixelClusterBrush2D`는 전체 원본 또는 선택 영역의 경계 사각형을 캡처한다. 선택 영역의 투명한 셀도 경계 계산에 포함하므로 장식 주변의 의도한 여백을 유지할 수 있다.

```ts
import {
  capturePixelClusterBrush2D,
  serializePixelClusterBrush2D,
  parsePixelClusterBrush2D,
} from 'poku-pixel-fx/core/pixel-cluster-brush';

const brush = capturePixelClusterBrush2D(source, selectedCells, {
  name: '직접 그린 잎',
  // 잘라낸 브러시 내부의 좌표다. 원본 캔버스의 좌표가 아니다.
  anchor: [3, 6],
});
const json = serializePixelClusterBrush2D(brush);
const reopened = parsePixelClusterBrush2D(json);
```

선택을 생략하면 전체 원본을 캡처한다. 브러시 크기는 가로·세로 각각 128픽셀까지다. 더 큰 원화를 사용하면 필요한 부분만 선택한다. 기본 기준점은 가운데 셀이며, 짝수 크기에서는 가운데 네 셀 중 왼쪽 위에 해당하는 셀을 사용한다. 기준점은 브러시를 돌리거나 뒤집을 때 함께 이동한다.

`poku-pixel-cluster-brush/v1` JSON에는 이름, 너비·높이, packed straight RGBA, 독립 실루엣 마스크와 기준점을 저장한다. 낮은 알파의 RGB, 알파가 0인 셀의 숨은 RGB, 0~255 마스크 값도 정확하게 저장한다. 선택 사각형 안에 있지만 실제 선택에서 빠진 셀은 원본 색을 보관하면서 마스크를 0으로 둔다.

## 일정한 간격으로 군집 그리기

```ts
import { stampPixelClusterBrush2D } from 'poku-pixel-fx/core/pixel-cluster-brush';

const result = stampPixelClusterBrush2D(sourceBeforeStroke, pointerSamples, brush, {
  spacing: 8,
  rotation: 90,
  flipX: false,
  flipY: false,
  wrap: false,
  selection: selectedCells,
  protectedMask: detailsToKeep,
  alphaLock: false,
});
// result.sprite: 새로운 픽셀/마스크 버퍼
// result.touched: 최종 결과가 원본과 다른 셀
```

| 옵션 | 기본값 | 동작 |
| --- | --- | --- |
| `spacing` | `1` | 획의 전체 길이를 따라 1~256픽셀 정수 간격으로 배치 |
| `rotation` | `0` | 뒤집은 다음 시계 방향으로 0°·90°·180°·270° 회전 |
| `flipX`, `flipY` | `false` | 브러시 원본을 좌우·상하 반전 |
| `wrap` | `false` | 브러시 전체 영역을 반대쪽 캔버스 경계로 이어 붙임 |
| `selection` | 없음 | 선택한 목적지 셀만 변경 |
| `protectedMask` | 없음 | 보호한 목적지 셀 보존 |
| `alphaLock` | `false` | 이미 보이는 목적지의 알파·실루엣은 유지하고 RGB만 변경 |

간격은 포인터 이벤트마다 다시 시작하지 않는다. 처음 점에서 0, 간격, 간격의 두 배… 거리마다 브러시를 놓으므로 같은 직선에 마우스 샘플이 더 많이 들어와도 같은 결과가 나온다. 끝점이 간격에 맞지 않으면 마지막에 별도 브러시 자국을 추가하지 않는다. 클릭 한 번은 브러시 한 번을 배치한다.

각 미리보기에는 **획을 시작하기 직전의 동일한 원본**과 현재까지의 전체 점 목록을 전달한다. 직전 미리보기에 다시 덧칠하면 실행 취소 단위와 겹침 순서가 달라질 수 있다. 함수 자체는 입력 원본과 브러시를 변경하지 않는다.

겹치는 자국은 경로 순서대로 적용한다. 브러시 내부 셀은 원본의 행 순서대로 적용한다. 모든 변환은 정수 셀의 위치만 바꾸므로 RGB 보간이나 알파 누적이 없다. 알파가 0이거나 독립 마스크가 0인 브러시 셀은 목적지에 손대지 않는다. 투명한 부분으로 기존 그림을 지우는 도구는 아니다.

필압 값이 0이면 해당 샘플을 건너뛴다. 양의 필압은 저장한 군집을 그대로 배치하며 굵기, 알파나 픽셀 배치를 바꾸지 않는다. 일반 연필의 정수 지름 필압과 구분되는 동작이다.

## 원본을 고정해서 복제하기

```ts
import { clonePixelBrush2D } from 'poku-pixel-fx/core/pixel-cluster-brush';

const result = clonePixelBrush2D(
  sourceBeforeStroke,
  pointerSamples,
  [16, 24],  // 원본에서 읽을 기준 셀
  [48, 24],  // 그릴 위치의 기준 셀
  {
    size: 5,
    tip: 'round',
    pixelPerfect: true,
    symmetry: 'none',
    wrap: false,
    selection: selectedCells,
    protectedMask: detailsToKeep,
  },
);
```

원본 기준점에서 목적지 기준점으로의 정수 이동량이 획 전체에 유지된다. 예를 들어 원본 X=16에서 목적지 X=48로 복제하면 목적지 X=52는 원본 X=20을 읽는다. 복제한 위치가 원본 읽기 영역과 겹쳐도 이미 그린 결과를 재귀적으로 다시 읽지 않는다. 스트로크를 시작하기 전의 픽셀을 끝까지 참조한다.

원본 읽기 위치가 캔버스 밖이면 해당 목적지 셀을 유지한다. 반복 옵션을 켜면 원본 읽기 위치도 반대쪽 경계로 이어 붙인다. 숨겨지거나 투명한 원본 셀 역시 목적지를 변경하지 않는다. 선택·보호·투명도 잠금은 목적지 편집을 제한한다.

클론의 대칭 옵션은 그릴 영역을 반사한다. 원본을 읽는 기준점의 이동량은 그대로 유지하며, 원본 무늬 자체를 반전하지 않는다. 무늬의 좌우·상하 반전이 필요하면 군집으로 캡처한 뒤 반전 옵션을 사용한다.

## 타일 경계를 잇는 일반 연필

기존 `rasterizePixelBrush2D`에도 `wrap:true`가 추가된다. 꺼 두면 기존 결과가 유지된다.

```ts
import { rasterizePixelBrush2D } from 'poku-pixel-fx/core/pixel-brush';

const mask = rasterizePixelBrush2D(32, 32, [
  { x: 30, y: 12 },
  { x: 34, y: 13 },
], { size: 3, pixelPerfect: true, wrap: true });
```

포인터의 좌표는 경계를 넘어간 값 그대로 전달한다. 오른쪽 끝 31에서 반대편 1로 이동하려면 연속 좌표 31→33을 사용한다. 먼저 31→1로 나머지 연산을 하면 본래 캔버스 중앙을 가로지르는 다른 선분이 된다. 도구는 연속 선분을 먼저 보간한 뒤 각 셀과 브러시 끝의 전체 영역에 나머지 연산을 적용한다.

격자의 가로 또는 세로가 1인 경우도 처리한다. 브러시가 작은 타일보다 큰 경우 여러 셀이 같은 목적지에 도달할 수 있다. 일반 연필은 이진 마스크의 합집합이며, 색이 여러 개인 군집 브러시는 위에서 설명한 순서에 따라 마지막 셀을 남긴다.

반복 옵션은 자유 브러시, 직선과 클론에 적용된다. 사각형·타원 도형에 `wrap:true`를 넘기면 명시적인 오류를 반환한다.

## 보존 범위와 작업 예산

군집과 클론은 색상과 독립 실루엣을 편집한다. 입력의 다른 메타데이터·발광·높이·법선은 기존 일반 그리기 API처럼 원본 참조를 유지한다. 여러 표면 채널이나 캐릭터의 소켓까지 함께 옮겨야 하면 선택 변형 API를 사용한다.

최대 캔버스는 가로·세로 4096픽셀이다. 점 좌표는 ±1,048,576 범위, 점 목록과 군집 샘플은 최대 65,536개, 군집의 실제 셀 방문은 최대 16,777,216회다. 비반복 경로는 화면 밖의 샘플 구간을 건너뛰면서 전체 간격 위상을 보존한다. 반복 연필은 최대 262,144개 보간 셀, 16,777,216회 브러시 셀 방문과 기존 붓 스팬 예산을 적용한다. 브러시 JSON은 UTF-8 1MiB까지다.

검증에 실패하거나 작업 예산을 넘으면 입력을 변경하지 않고 오류를 반환한다. 자동 검사는 좌표·색·알파·마스크·간격과 원본 불변성을 확인하며, 반복 무늬의 미술적 완성도를 인증하지 않는다.
