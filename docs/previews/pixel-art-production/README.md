# 픽셀 색 편집의 실제 출력

다음 명령으로 재현한다.

```sh
npm run build
node tools/preview-pixel-art-production.mjs
```

모든 그림은 192×112 네이티브 원화에서 실제 도구 API를 실행한 결과이다.
기존 FX 카탈로그의 효과를 바꾸거나, 별도로 생성한 그림을 도구 결과처럼 사용하지 않는다.

## 공통 원본

`createPixelArtStudy2D('cloth', 41, true)`의 곡선 실루엣과 명시적인 천의 높이를
시작점으로 사용한다. 실제 천 재질 셰이더로 주름·직조의 명암을 만들고, 생성
스크립트에서 금색 자수 경로와 금속 테두리·보석의 형태를 직접 작성한다.

자수와 보석 디테일은 색 편집 기능이 자동으로 그린 결과가 아니다. 비교는
이렇게 미리 작성한 공통 원본의 색을 바꾸며 형태와 보호 디테일을 유지하는지 보여준다.

## 비교 읽기

| 행 | 바꾸는 영역 | 확인할 내용 |
| --- | --- | --- |
| 정확한 RGB 교체 | 천의 16색 | 각 색의 역할을 일대일로 바꾸고 자수·금속·보석은 그대로 유지 |
| 명암 램프 | 천의 Oklab 밝기 | 원화의 주름 명암을 다른 14색 계열로 매핑, 장식 보호 |
| 직선 램프 | 보석 내부 | 명시한 두 점을 따라 금색 10단계 배치, 기존 작은 내포물 보호 |
| 원형 램프 | 보석 내부 | 작성한 중심·반지름에 따라 청록색 11단계 배치, 형태·알파 유지 |

직선·원형 램프는 의도한 영역에 새로운 색 구조를 배치하는 도구이다. 기존의
전체 재질을 덮으면 그 재질의 색 구조도 대체된다. 이 예제는 보석 내부를 선택해
주변의 천·금속·자수 구조를 보존하고, 작은 강조점은 보호 영역으로 남긴다.

## 파일

- `comparison-native.png`: 원본 셀을 그대로 표시한 1× 비교.
- `comparison-3x.png`: 각 원본 셀을 정확히 3×3으로 반복한 비교. 새 디테일을 만들지 않는다.
- `source-native.png`: 공통 원본 RGBA.
- `exact-swap-native.png`, `value-map-native.png`, `linear-map-native.png`, `radial-map-native.png`: 각 작업의 네이티브 RGBA 출력.
- `source.poku-pixel-art.json`: 원본과 명시적인 표면 채널을 포함한 v2 프로젝트.
- `*.poku-pixel-art.json`: 공통 원본과 한 개의 희소 그림 레이어로 결과를 다시 열 수 있는 프로젝트.
- `evidence.json`: 설정·소스/출력 해시·색 수·경계·알파·독립 실루엣·높이·법선·재질 보존 기록.

저장한 프로젝트의 색 편집은 **희소 그림 레이어에 구운 결과**이다. 원본 레이어를
유지하고 결과를 숨기거나 수정할 수 있지만, 해당 레이어에서 이전 램프 설정을
자동으로 다시 조절하는 형식은 아니다. 원래 설정은 `evidence.json`에 기록한다.

이 비교의 색 수와 바뀐 셀 수는 작업 범위를 설명한다. 미술적 완성도 점수가 아니다.
자동 생성한 기록의 `visualReview`는 실제 이미지를 확인하기 전에는 확인 완료로
바뀌지 않는다. 그림을 원본 크기와 3×에서 모두 살펴본 관찰은 별도로 기록한다.

## 실제 이미지 확인 기록

아래 두 파일을 이미지 뷰어에서 직접 열어 원본 크기와 최근접 3×를 확인했다.
이 기록은 숫자 검사에서 자동 추론한 결과나 사용자 승인 기록이 아니다.

| 파일 | 확인한 파일의 SHA-256 |
| --- | --- |
| `comparison-native.png` | `349b6b28727e7e111e8585914195cea3f0dc367c65187c1ce245b659a3053fb7` |
| `comparison-3x.png` | `122f1f621ec16cbb3a1cda0298ed64e66f45c6e45331079bfb34a5acee852518` |

- 원본은 곡선 외곽의 보라색 천, 금색 테두리·자수, 푸른 보석으로 읽힌다.
- 정확한 교체 결과에서는 천이 청록색으로 바뀌지만 직조 무늬의 셀 배치와
  금색 장식·보석의 색 구분이 남는다.
- 명암 매핑에서는 천의 큰 주름 밝기가 파란 계열로 이어진다. 출력 색 수를
  제한하므로 일부 가까운 색이 같은 단계에 묶이는 절충이 있다.
- 직선 램프의 보석은 대각선 금색 띠로, 원형 램프는 밝은 중심과 청록색
  동심 단계로 보인다. 둘 다 원래의 보석 재질 색 구조를 의도적으로 바꾸는
  예시이며, 원래의 형태 명암을 자동 복원한 결과로 해석하지 않는다.
- 보호한 작은 강조선과 주위의 천·자수는 계속 보인다. 3× 비교에서 원본 셀은
  선명한 블록으로 반복되고, 별도의 블러나 확대 디테일이 들어가지 않는다.

보존 측정에서는 네 결과 모두 같은 가시 경계 `(25,16)`, `142×80`, 9,656개의
가시 셀을 유지했다. 천을 바꾸는 두 작업은 각각 6,165셀, 보석을 바꾸는 두 작업은
각각 999셀의 RGB를 수정했다. 알파·실루엣·보호 영역·선택 밖·표면 채널의
일치는 `evidence.json`에 검사 범위와 함께 기록되어 있다.
