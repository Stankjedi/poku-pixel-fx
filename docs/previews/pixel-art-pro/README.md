# Pixel Art Pro 작성 예제

`node tools/preview-pixel-art-pro.mjs`로 재현하는 독립적인 픽셀아트 작성 예제이다.
기존 FX 카탈로그의 그림이나 기본 렌더링을 교체하지 않는다. 생성 도구의 코드가 곡선,
소재 구분, 색 덩어리, 금속 세공과 천의 주름을 직접 작성한다.

## 비교 그림

- `comparison-native.png`: 224×160 네이티브 픽셀 예제를 그대로 표시하는 비교.
- `comparison-3x.png`: 모든 원본 셀을 정확히 3×3으로 반복한 비교. 새 디테일이나 블러를 추가하지 않는다.
- `relight-albedo-native.png`, `relight-warm-native.png`, `relight-cool-native.png`: 같은 문양과 높이에서 조명만 변경.
- `tile-open-repeat-native.png`, `tile-seamless-repeat-native.png`: 같은 나무 재질의 비주기적/주기적 작성 모드를 2×2로 반복.
- `tile-seamless-3x3-native.png`: 반복 경계를 확인하는 3×3 네이티브 타일.
- `animation-source-native.png`, `animation-shared-native.png`: 4개의 cel 전체에서 색을 추출한 24색 공통 팔레트.
- `animation-cel-0-native.png`부터 `animation-cel-3-native.png`: 각각 독립적인 112×80 네이티브 cel.
- `evidence.json`: 사용한 설정, 소스 해시, 출력 해시와 측정한 알파/채널/색상 보존 정보.

## 작성 의도

첫 번째 예제는 굽은 천의 외곽과 큰 주름, 청록색 에나멜, 금속 테두리와 곡선 세공,
눈물방울 모양 보석을 따로 작성한다. 큰 색 덩어리 안에 구조를 넣고, 그 위에 1셀짜리
선과 작은 강조점을 배치한다. 재조명은 그림에서 재질이나 구조를 추측하지 않는다.
자료의 평탄한 원래 색을 보여주는 것은 조명 입력을 드러내기 위한 것이며,
단색 원본이 완성된 작품이라는 뜻은 아니다.

두 번째 예제의 비교는 기존 PNG의 경계를 고쳐주는 기능이 아니다. 같은 나뭇결
레시피를 열린 좌표계와 반복 좌표계에서 각각 작성한다. 반복 버전은 색뿐 아니라
높이와 차폐의 이웃까지 같은 경계 조건을 사용한다.

세 번째 예제의 cel들은 각각 자기 해상도에서 곡선과 무늬를 래스터화했다. 큰 원본을
작게 보간한 결과가 아니다. 공통 팔레트는 프레임별 대표색이 따로 움직이는 원인을
없애는 도구이며, 명시한 천의 주름 변화나 실제 조명 변화는 그대로 남는다.

검사 수치와 미술적 판단은 구분한다. 자동 생성한 기록에는 시각적 확인을 완료했다고
기입하지 않는다. `evidence.json`의 `visualReview`는 사람이 실제 네이티브 결과를
확인한 뒤 별도로 기록할 수 있다.
