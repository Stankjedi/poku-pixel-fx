# 실제 생성물 관찰 기록

관찰자: 구현 에이전트. 관찰일: 2026-11-05. 대상은 동봉된 `recipe-native-frames.png`, `recipe-layer-diagnostics.png`의 native 320×180 샘플입니다. 이 기록은 정지 이미지에 대한 관찰이며 사용자 승인 또는 full-speed playback 관람 기록은 아닙니다.

## 첫 인상과 수정

- 투척 검: 회전 위상에 따라 blade의 밝은 bevel과 어두운 면, guard와 grip이 나뉩니다. 잔상이 주형태를 삼키지 않습니다. 마지막 샘플에서 검 대신 접촉 불티가 남습니다. 실제 재생에서 투척과 소멸이 얼마나 명확한지는 추가 관람 대상입니다.
- 검격 리본: 날이 밝은 바깥 edge를 이끌고 넓은 면이 뒤따릅니다. 뒤쪽 잔상과 접촉 뒤의 소멸을 별도 sample에서 볼 수 있습니다.
- 낙뢰: 굵은 주 방전과 가는 분기가 구별되고 바닥의 도착점이 밝습니다. glow를 꺼도 방전 경로가 남습니다.
- 폭발: 첫 출력에서 같은 크기의 원들이 규칙적으로 둘러선 꽃 모양으로 읽힐 위험이 있었습니다. 그 부분을 seed가 고정된 불규칙한 압력 외곽선과 비대칭의 밝은 core, 서로 다른 상승 속도의 냉각 연기로 수정했습니다. 수정된 native sheet를 다시 확인했습니다.
- 불꽃: 연결된 세 개의 면과 하단 밝은 core가 불의 중심을 만들고, 불티와 연기는 위쪽에서 분리됩니다. 정지 샘플 사이의 형태 차이는 보이나 temporal smoothness를 이 기록에서 판정하지 않습니다.
- 포털: 어두운 내부와 타원형 앞뒤 rim이 구별됩니다. glow-off에서도 입구가 유지됩니다. 실제 배우가 통과하는 장면은 이 reference sheet에 포함되지 않습니다.

## 최종 출력 경계 수정

접촉 파편의 감속과 바닥 도달을 반영하고 폭발의 압력 전면을 지면 타원으로 바꾼 뒤 두 sheet를 다시 생성하여 열었습니다. 마지막 투척 검 샘플의 불티가 접촉점에 모이고, 폭발 아래 지면 파문과 상승하는 본체가 분리되는 것을 확인했습니다. 기본 설정 여섯 효과의 출력 검사에서 캔버스 바깥 그리기 경고는 더 이상 나오지 않았습니다. 이 정지 이미지 관찰로 재생 속도나 최종 게임 배치의 품질까지 판정하지 않습니다.
