## SUIT Variable — offline Studio interface font

`SUIT-Variable.woff2` is an **unmodified** copy from the official
[sun-typeface/SUIT v2.0.5 release](https://github.com/sun-typeface/SUIT/tree/v2.0.5).
It is Copyright (c) 2022, SUNN (http://sun.fo/suit), with Reserved Font Name
**SUIT**, and is distributed under the SIL Open Font License 1.1. The complete
upstream copyright notice and license are in [OFL-SUIT.txt](OFL-SUIT.txt).

- Font source: https://raw.githubusercontent.com/sun-typeface/SUIT/v2.0.5/fonts/variable/woff2/SUIT-Variable.woff2
- License source: https://raw.githubusercontent.com/sun-typeface/SUIT/v2.0.5/LICENSE
- File size: 624,536 bytes.
- SHA-256: `aa894a204d5a6fbae259dac6868d350cbd373a390caee0313f92946af741df23`.
- Variable weight axis: 100–900. The upstream binary reports Version 2.040.

The cmap contains **2,668 modern Hangul syllables**, including all 252 distinct
Hangul syllables in the current `gallery/studio.html` and `gallery/studio.ts`
interface text, checked on 2026-11-05. This is not a claim that the font covers
all 11,172 modern Hangul syllables. Unsupported characters continue through the
system fallback font chain.

Studio registers this file under the CSS alias `Poku Studio UI`; the font binary,
internal SUIT names, outlines, cmap and variable axes have not been changed or
subset. The alias does not create a modified font. The font and license are
served from the application's own files; no runtime font CDN is required.
