# 공개 공유 갤러리 운영

`/shared`는 로그인한 사용자가 PNG 결과물을 선택해 공개하는 갤러리다. 업로드 전에 게시 권한과 법적 책임에 동의해야 한다. 이 동의는 권리의 실제 보유 여부를 증명하지 않는다. 신고는 저장소 Issues에서 작품 원본 URL과 사유를 받아 검토한다. 공개 이슈에 개인정보를 올리지 않도록 안내한다.

서버는 파일당 5 MiB, 가로·세로 각 2048픽셀, PNG 시그니처·청크 CRC를 확인한다. 해상도와 파일 검사만으로는 픽셀 아트 여부나 이미지 내용, 게시 권한을 보장할 수 없으며 PNG 전체 디코딩 검사는 하지 않는다. D1은 계정별 활성 게시물 50개 및 10분 5회·24시간 20회의 업로드 시도 제한을 원자적으로 적용한다. 공유물은 누구나 볼 수 있고 인증된 게시자만 삭제할 수 있다. R2와 D1 바인딩 및 `drizzle/0000_living_human_torch.sql` 적용이 필요하며 DB 오류 시 업로드를 거부한다.

R2 저장과 D1 예약은 단일 트랜잭션이 아니다. 비정상 종료 또는 부분 장애 시 예약과 실제 파일이 일치하지 않을 수 있으므로 관리자가 정기적으로 양쪽을 확인하고 복구해야 한다. 계정별 제한은 전체 버킷 용량 제한이나 다중 계정 악용 방어를 보장하지 않는다. 게시물 자동 심사, 운영자 일괄 삭제 UI, 신고 자동 처리 및 이용자 권리 실증은 제공하지 않는다. 운영자는 저장소 접근 권한과 신고 검토·삭제 절차를 별도로 마련해야 한다.

| TODO | 운영자 신고 검토, 부분 장애 복구 및 전체 용량 관리 절차 확립 |

| 상태 | 공유 갤러리 개선 |
|---|---|
| DONE | 공유 작품과 태그를 이펙트 화면 검색에 연결 |
| DONE | 태그 게시 및 기존 무태그 게시물 호환 |

| DONE | 작성자의 제목·태그·PNG 수정과 서버 소유권 확인 |
| TODO | 실제 배포 환경에서 수정 및 검색 흐름 검증 |

공유 검색과 전체 수는 모든 공유 목록 페이지를 불러와 계산한다. 최신순은 확인된 기본 효과 추가 시각과 공유 게시 시각을 비교하며, 시각이 없는 기본 효과는 뒤에 기존 순서로 표시한다. 기존 무태그 게시물도 표시된다.

| DONE | 전체 개수 표시와 공유 게시물 최신순 선택 |
