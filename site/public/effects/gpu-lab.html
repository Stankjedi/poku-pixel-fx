타일의 256개 후보 한도를 넘으면 해당 타일은 전체 도형을 검사합니다. 픽셀과 입자를 생략하지 않습니다.
WebGPU 어댑터를 확인하고 있습니다.
타일 검사를 실행하면 실제 GPU 후보 수를 읽습니다. 일반 재생에는 읽기 작업이 없습니다.
이 화면의 GPU 경로도형 명령은 CPU가 작성합니다. 공간 분류, 픽셀 래스터, 장식 입자 시뮬레이션과 HDR 합성은 GPU에서 실행합니다. 기존 Studio의 절차적 이펙트는 별도로 CPU 도형 생성과 GPU 후처리를 사용합니다.
비교와 CPU 대체 표시픽셀 비교는 같은 시점의 직접/타일 출력을 비교합니다. 후보 수의 감소가 곧 실행시간의 감소를 뜻하지는 않습니다. WebGPU를 사용할 수 없으면 같은 장면의 CPU 기준 정지화면을 worker에서 계산하고 원인을 표시합니다.
